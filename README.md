# nassauTickets

## Descrição

O nassauTickets é um Sistema de Controle de Atendimento desenvolvido para um Laboratório de Análises Clínicas.

O sistema tem como objetivo organizar o fluxo de atendimento por meio do gerenciamento de senhas, chamadas, guichês e registros dos atendimentos.

## Objetivo

Desenvolver uma solução digital para facilitar o controle das filas e dos atendimentos realizados no laboratório, proporcionando maior organização e permitindo o acompanhamento das chamadas por meio de um painel.

## Tecnologias

- React
- Node.js
- Express
- MySQL
- Git e GitHub

## Arquitetura

O sistema será desenvolvido utilizando uma arquitetura separada em frontend e backend.

- **Frontend:** responsável pela interface utilizada pelos clientes, atendentes e gerentes.
- **Backend:** responsável pelas regras de negócio, processamento das solicitações e comunicação com o banco de dados.
- **Banco de dados:** responsável pelo armazenamento das senhas, usuários, atendimentos e registros de auditoria.
