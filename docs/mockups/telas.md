# Mockups — nassauTickets

## 1. Tela do Totem

Tela utilizada pelo cliente para emitir uma senha.

### Elementos

- Título do sistema.
- Botão "Senha Prioritária".
- Botão "Senha Geral".
- Botão "Retirada de Exames".
- Exibição da senha emitida.
- Mensagem orientando o cliente a aguardar o atendimento.

---

## 2. Painel de Atendimento

Tela pública utilizada para informar as últimas senhas chamadas.

### Elementos

- Nome do sistema.
- Senhas chamadas recentemente.
- Número do guichê correspondente.
- Exibição das cinco últimas senhas chamadas.
- Destaque para a chamada mais recente.

O painel não deverá exibir a próxima senha que será chamada.

---

## 3. Tela de Atendimento

Tela utilizada pelo atendente para controlar os atendimentos.

### Elementos

- Identificação do guichê.
- Quantidade de senhas aguardando.
- Botão "Chamar próxima senha".
- Botão "Chamar novamente".
- Botão "Iniciar atendimento".
- Botão "Finalizar atendimento".
- Exibição da senha atualmente chamada.

---

## 4. Tela de Login

Tela utilizada para autenticação dos atendentes e gerentes.

### Elementos

- Campo de login.
- Campo de senha.
- Botão "Entrar".
- Mensagem de erro para credenciais inválidas.

---

## 5. Tela Administrativa

Tela destinada ao gerente do sistema.

### Elementos

- Gerenciamento de atendentes.
- Gerenciamento de guichês.
- Consulta de relatórios.
- Consulta de auditoria.
- Informações gerais do sistema.
