# Acessibilidade e Usabilidade — nassauTickets

## Acessibilidade

O sistema deverá facilitar a utilização por diferentes usuários, considerando principalmente a clareza das informações apresentadas.

### Requisitos

- Os textos deverão possuir tamanho adequado para leitura.
- Os botões deverão apresentar textos claros e objetivos.
- As informações importantes deverão possuir destaque visual.
- O sistema deverá evitar excesso de elementos na tela.
- As cores não deverão ser utilizadas como único meio de transmitir uma informação.
- O painel deverá apresentar as senhas e os guichês de forma facilmente identificável.
- O sistema deverá utilizar linguagem simples e objetiva.

## Usabilidade

As telas deverão possuir uma organização simples e consistente.

### Requisitos

- O cliente deverá conseguir emitir uma senha com poucos passos.
- As opções de atendimento deverão estar claramente identificadas.
- O atendente deverá conseguir visualizar rapidamente a fila e a senha atual.
- As ações de iniciar e finalizar atendimento deverão ser facilmente identificáveis.
- Mensagens de confirmação e erro deverão ser apresentadas de forma clara.
- A navegação entre as funções deverá ser simples e consistente.
