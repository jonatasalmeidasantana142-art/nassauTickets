# Segurança e LGPD — nassauTickets

## Segurança

O sistema deverá utilizar autenticação para controlar o acesso às funções destinadas aos atendentes e gerentes.

### Requisitos

- O acesso às funções administrativas deverá exigir login.
- As permissões deverão respeitar o perfil do usuário.
- Senhas de usuários não deverão ser armazenadas em texto puro.
- O sistema deverá validar os dados recebidos pelo frontend.
- O sistema deverá registrar ações relevantes para fins de auditoria.
- O acesso às informações deverá ser restrito de acordo com as permissões de cada usuário.

## LGPD

O sistema deverá considerar os princípios da Lei Geral de Proteção de Dados (LGPD), especialmente em relação à proteção e ao uso adequado de dados pessoais.

### Medidas previstas

- Coletar somente os dados necessários para o funcionamento do sistema.
- Restringir o acesso aos dados conforme a função do usuário.
- Evitar a exposição desnecessária de informações pessoais no painel público.
- Manter registros de auditoria das operações relevantes.
- Proteger os dados armazenados no banco de dados.
- Definir mecanismos para correção ou exclusão de dados quando aplicável.
